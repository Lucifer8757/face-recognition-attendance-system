Biometric Privacy & Ethics Safeguards
Complies with institutional privacy principles for handling student biometric identification data.
Informed Voluntary Consent

Biometric enrollment strictly requires explicit consent verification. Students without consent are not scanned or enrolled.

Non-Public Isolated Storage

Embeddings and facial photos are stored outside the public /static/ directory in data/secure_storage/, accessible only to authenticated administrators.

Right to Erasure (Deletion)

Administrators can delete a student's profile at any time, immediately purging their 128D mathematical vector, photos, and attendance traces.

Zero Cloud Transmission

All inference runs 100% locally on the host machine using native OpenCV ONNX models. No biometric features leave the premises.

Unrecognized ≠ Proof of Absence

Failure to match is never treated as definitive absence. Authorized administrators can manually verify attendance via the override portal.

Computer Vision System Limitations
  • Lighting Variance: Low illumination or strong backlighting reduces feature extraction precision.
  • Facial Occlusions: Masks, dark glasses, or excessive tilt obstruct key facial landmarks (eyes, nose tip, mouth corners).
  • Basic 2D Camera Vulnerability: Standard consumer webcams capture 2D RGB imagery and lack 3D structured light or infrared depth sensors. Hence, high-quality photographs could spoof standard 2D systems without hardware liveness detection.
  • Scale & Database Size: Linear cosine search is instantaneous for classroom sizes (< 1,000 students); larger university deployments would require indexed vector stores (e.g. FAISS).
